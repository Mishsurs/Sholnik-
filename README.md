# Школьник+ — стартовый Android-проект

Открыть папку проекта в Android Studio и дождаться Gradle Sync.
Затем запустить конфигурацию `app` на Android-эмуляторе или устройстве.

## Что уже есть
- Jetpack Compose интерфейс
- Главная страница
- Разделы оценок, расписания и домашних заданий
- Демонстрационный средний балл

## Важно
Все отображаемые оценки, уроки и задания — демонстрационные данные.
Проект пока НЕ подключается к АСУ РСО и не запрашивает логины/пароли.
Перед интеграцией необходимо получить и проверить официальный разрешённый
механизм доступа. Не вводите пароль Госуслуг в стороннее приложение.

## Следующий этап
1. Уточнить официальный путь интеграции для Самарской области.
2. Реализовать авторизацию через поддерживаемый провайдер без сбора пароля.
3. Добавить защищённое хранение токенов/сессии и корректное обновление.
4. Подключить реальные оценки, расписание и задания.
